# Reel · Plataforma para inmobiliarias

Vídeo vertical de 38 segundos, 1080 × 1920, H.264/AAC. La versión principal incluye música instrumental original generada localmente; también hay una versión sin audio y una portada PNG. No contiene locución. Las capturas muestran páginas públicas de ONO Prop; la fotografía de oficina es ilustrativa y no representa a un cliente real.

## Texto sugerido para la publicación

Tu inmobiliaria hace mucho más que publicar. 🏢

Con ONO Prop podés reunir en una plataforma modular:

- Publicación de inmuebles y emprendimientos, con tu marca y sitio propio.
- Herramientas de difusión para Instagram y Mercado Libre.
- Administración de inmuebles, alquileres y consorcios.
- Tasaciones, mapas y datos de parcelas.
- Cobros, liquidaciones y facturación electrónica.
- Equipos, sucursales y colaboración con otras inmobiliarias.

Elegí los módulos que necesitás. Pedí una demostración desde el enlace de nuestra biografía o ingresá a **onoprop.com/demo**.

Las integraciones con Instagram, Mercado Libre, Mercado Pago y ARCA están sujetas a los requisitos, permisos y configuración de cada cuenta y plataforma.

## Archivos

- `ONO_Prop_Reel_Plataforma_Inmobiliarias_Con_Musica.mp4`: versión recomendada para publicar.
- `ONO_Prop_Reel_Plataforma_Inmobiliarias.mp4`: versión sin audio.
- `ONO_Prop_Reel_Plataforma_Inmobiliarias_Cover.png`: portada.
- `ONO_Prop_Plataforma_Musica_Original.wav`: música editable.
- `generate.mjs` y `add-music.mjs`: fuentes reproducibles. `generate.mjs` necesita FFmpeg, Playwright, Chrome y acceso a las páginas públicas de ONO Prop.

Los archivos de `assets/` son capturas y escenas intermedias para edición. No contienen pantallas privadas de clientes.
